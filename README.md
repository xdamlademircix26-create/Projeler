# Store Chain Sales and Revenue Analysis 
This project, in C language , is devoloped to reinforce the logic of 'nested loop' 'single-selection statement' and 'accumulator' console-based  data analysis program

## Purpose of Project
The purpose of project is collect data from user regarding a specific number of branches and categories , calculate total turnover of each branch store and detect accurately identify the store with the highest revenue

## Features
** Dynamic Input : Dynamically get input from user regarding number of store branches and categories
** Nested Loop : Provide hierarchical data circulation between branch and category
** Accumulator Logic : Calculate total revenue of each branch
** Compare Algorithm : Detect the store with highest revenue and analyse it
